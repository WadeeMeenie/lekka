# Launch research — reviewed 14 October 2026

Primary sources below were retrieved during this audit. Where no publication date was visible, the date is the access date, not an invented update date. Product observations are based on official descriptions, not logged-in competitor usability tests. Implementation status describes inspected repository evidence; live behavior remains unverified.

## Mandatory security gates and applicable legal review

| Source / date | Finding and why it matters | Lekka implementation / evidence / status |
|---|---|---|
| [Supabase production checklist](https://supabase.com/docs/guides/deployment/going-into-prod), accessed 2026-10-14 | Production requires security, operational and auth configuration review. | **Partially implemented**: existing release gates, RLS migrations and CI. Verify backups, email capacity, monitoring and effective permissions on target project; live checks BLOCKED. |
| [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security), accessed 2026-10-14 | Grants and row policies are separate controls; authorize ownership and test all operations. | **Partially implemented**: owner-scoped RPC migrations exist. Reconcile deployed policies and test anon/A/B/moderator roles. Existing SQL string tests are not execution evidence. |
| [Storage access control](https://supabase.com/docs/guides/storage/security/access-control), accessed 2026-10-14 | Object policies must govern upload/read/update/delete. | **Partially implemented**: private media and cleanup code exist. Browser byte reading corrected locally. Signed URLs, expiry, replacement and cross-account access need live tests. |
| [Edge authentication](https://supabase.com/docs/guides/functions/auth), accessed 2026-10-14 | Gateway authentication and handler authorization must match the caller model. | **Partially implemented**: user-facing nearby handlers and server cleanup/payment functions exist. Inspect deployed versions, secrets and grants; do not treat verify_jwt=false alone as proof of exposure. |
| [Password security](https://supabase.com/docs/guides/auth/password-security), accessed 2026-10-14 | Password protection must be enforced by the server. | **Partially implemented**: client rules exist; old release doc says leaked-password protection disabled. Current setting unverified. Verify email confirmation, recovery and rate limits. |
| [Supabase changelog](https://supabase.com/changelog), accessed 2026-10-14 | Current changes include Data API exposure defaults and logs API changes; avoid assuming old platform behavior. | **Partially implemented**: explicit grants exist; effective project exposure unknown. Node 22 CI and TypeScript 5.9 satisfy listed runtime direction. Markdown changelog fetch failed; HTML index reviewed. |
| [OWASP ASVS releases](https://github.com/OWASP/ASVS/releases), stable 5.0.0, 2025 | Use verifiable requirements for authorization, sessions, input handling and file uploads. | **Partially implemented**: auth/services/tests exist. Add executed multi-user authorization, abuse and upload tests; no ASVS certification claimed. |
| [POPIA Act 4 of 2013](https://www.gov.za/documents/protection-personal-information-act), 2013; commencement dates on source | Processing personal information requires a lawful basis, purpose, safeguards and data-subject rights. | **Not implemented / not evidenced in inspected routes**: complete privacy notice, retention schedule, access/correction/deletion process and operator/data-transfer assessment. Location and profile settings alone are insufficient. Qualified SA legal review required. |
| [Information Regulator POPIA guidance](https://inforegulator.org.za/popia/), accessed 2026-10-14; portal change 2025-04-01 | Security-compromise reporting uses the eServices portal; incident response needs accountable owners. | **Not implemented / not evidenced**: assign Information Officer and incident lead; prepare section 22 assessment, notification and evidence-preservation procedure with legal advice. |
| [ECTA 25 of 2002](https://www.gov.za/documents/electronic-communications-and-transactions-act), 2002, amendment references on source | Electronic-service and transaction obligations depend on actual offerings. | **Partially implemented / applicability unresolved**: inventory business/payment surfaces; counsel must assess disclosures, consumer rights and takedown obligations. No new payment flow added. |
| [Consumer Protection Act 68 of 2008](https://www.gov.za/documents/consumer-protection-act), 2008 | Consumer-facing claims and terms must be assessed for the actual service. | **Not implemented / not evidenced**: verify operator identity, support, terms, pricing/refunds if offered. Do not publish placeholder policies or claim compliance. |

## Recommended usability and performance requirements

| Source / date | Finding / relevance | Recommendation and repository status |
|---|---|---|
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/), Recommendation 2024-12-12 | Keyboard access, visible focus, accessible names and reachable targets support usable web journeys. | **Partially implemented**: many labels and 44dp targets exist; auth fields and modal focus need browser/screen-reader verification. Adopt AA as release target; do not claim conformance from static audit. |
| [Web Vitals](https://web.dev/articles/vitals), accessed 2026-10-14 | Good thresholds: LCP ≤2.5s, INP ≤200ms, CLS ≤0.1 at 75th percentile. | **Not implemented / not measured**: collect real-user web data with appropriate disclosure and lab traces on modest mobile hardware. Build time is not LCP; no invented before/after numbers. |
| [Supabase query optimization](https://supabase.com/docs/guides/database/query-optimization), accessed 2026-10-14 | Examine query plans and representative workloads before adding indexes. | **Partially implemented**: cursor feeds and index migrations exist. Live plans, cardinalities and staging load tests BLOCKED. |
| [Expo web development](https://docs.expo.dev/workflow/web/), accessed 2026-10-14 | Web needs compatible React Native Web and Metro runtime dependencies. | **Implemented in candidate**: missing web dependencies added within SDK 54 ranges, lockfile and frozen CI install added; export result tracked separately. |
| [Instagram safety](https://about.fb.com/news/2021/07/keeping-instagram-safe-and-secure/), 2021-07 | Reports should be available in content/account context. | **Partially implemented**: post actions expose reporting; verify receipt, moderation handling and blocking end-to-end. Do not copy branding. |
| [TikTok account privacy](https://support.tiktok.com/en/account-and-privacy/account-privacy-settings/making-your-account-public-or-private), accessed 2026-10-14 | Audience choice must have understandable consequences. | **Partially implemented**: profile lock exists; composer offers My community/My followers but maps non-Public to nearby. High-priority privacy mismatch to fix before launch. |
| [Facebook Home and Feeds](https://about.fb.com/news/2022/07/home-and-feeds-on-facebook/), 2022-07 | Separate discovery from intentional feed filtering and favourites. | **Partially implemented**: five tabs and feed preferences exist. Preserve user context, selection and useful empty/retry states. |
| [Reddit moderation queue](https://mods.reddithelp.com/hc/en-us/articles/360010090132-Moderation-Queue), accessed 2026-10-14 | Reporting needs an actionable moderation queue, not merely a submitted row. | **Partially implemented**: report tables/actions exist; operational ownership, review workflow and abuse handling unverified. |
| [Nextdoor community guidelines](https://help.nextdoor.com/articles/en_CA/Knowledge/community-guidelines), accessed 2026-10-14 | Local communities need clear participation rules and safety expectations. | **Partially implemented**: community guidelines fields exist. Review location disclosure, moderator permissions and reporting with real local journeys. Source extraction limited; no claim of direct UI inspection. |

Optional: new ranking systems, video-first feeds, elaborate animation and additional payment features are not prerequisites merely because competitors offer them. Preserve Lekka's established scope.
