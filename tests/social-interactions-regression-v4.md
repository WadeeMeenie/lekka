# Lekka social interaction regression checklist

- Tap React once: count increases by one.
- Tap React again: reaction is removed and count decreases by one.
- Rapid repeated taps never create duplicate reactions.
- Long-press React opens 👍 ❤️ 😂 😮 😢 😡.
- Selecting another emoji replaces the existing reaction.
- Comment opens the post detail/comment screen.
- Save invokes atomic save/unsave.
- Share opens the native share sheet.
- Not interested persists and shows: "You won't see posts like this in future."
- Verify the same post from another device/session to ensure state is server-backed.
